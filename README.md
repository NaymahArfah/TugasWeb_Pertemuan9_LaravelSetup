## Tentang Project

Project ini dibuat untuk memenuhi Tugas Rutin 9 (TR9) Pemrograman Web menggunakan framework Laravel.

Pada project ini dibuat beberapa halaman sederhana menggunakan Laravel, yaitu:
- Home
- About
- Contact

Project juga menggunakan routing, Blade View, Controller, Model, dan Migration.
